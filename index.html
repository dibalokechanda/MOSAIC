The Key Idea

Do independently trained pathology foundation models learn the same thing?

Central Hypothesis: Independently trained pathology foundation models learn different coordinate systems over a shared underlying morphological manifold.

If that holds, representations should be alignable, semantic neighbourhoods should survive alignment, features should transfer between models, and a downstream classifier should be able to live inside one shared space.

RQ1 — Similarity

How similar are the representation spaces of 18 pathology encoders measured by 7 similarity metrics?

RQ2 — Architecture vs Objective

Does the pretraining objective (vision SSL vs vision-language) drive latent geometry more than architecture?

RQ3 — Alignment

Can GCCA, Procrustes, optimal transport and other methods align several models into one shared latent space?

RQ4 — Downstream Impact

Does the aligned space improve downstream MIL classification on 14 molecular and morphological tasks?

RQ5 — Cross-model Transfer

Does a classifier trained on one encoder generalise to another encoder's features through the shared space?

Theory & Methods

A rigorous formulation of the 7 similarity metrics and 6 alignment methods used to compute cross-encoder representation alignments.

7 Similarity Metrics

Name Equation What it measures
Linear CKA $$\text{CKA}(K, L) = \frac{\text{HSIC}(K, L)}{\sqrt{\text{HSIC}(K, K) \text{HSIC}(L, L)}}$$ Linear correlation between representation spaces independent of orthogonal transformations.
Kernel CKA $$\text{CKA}(K, L) = \frac{\text{HSIC}(K, L)}{\sqrt{\text{HSIC}(K, K) \text{HSIC}(L, L)}}$$ Non-linear correlation capturing higher-order interactions using RBF kernels.
SVCCA $$\text{SVCCA}(X, Y) = \frac{1}{\min(d_1, d_2)} \sum_{i} \rho_i$$ Singular Value Canonical Correlation Analysis (PCA followed by CCA).
PWCCA $$\text{PWCCA}(X, Y) = \frac{\sum_i \alpha_i \rho_i}{\sum_i \alpha_i}$$ Projection Weighted CCA (weights CCA directions by variance explained).
Procrustes $$\min_{Q^T Q = I} \| X - Y Q \|_F^2$$ Distance after optimal orthogonal alignment.
Cosine RSA $$RSA(X, Y) = \frac{\text{vec}(S_X) \cdot \text{vec}(S_Y)}{\|\text{vec}(S_X)\| \|\text{vec}(S_Y)\|}$$ Representational Similarity Analysis using Cosine distance between samples.
Distance Correlation $$\text{dCor}(X, Y) = \frac{\text{dCov}(X, Y)}{\sqrt{\text{dVar}(X) \text{dVar}(Y)}}$$ Dependence measure robust to non-linear associations.

6 Alignment Methods

Name Equation What it aligns
GCCA $$\max_{W_i} \sum_{i,j} \text{Tr}(W_i^T X_i^T X_j W_j)$$ Generalized Canonical Correlation Analysis aligns multiple spaces to a shared latent representation.
MCCA $$\max_{W_i} \sum_{i \neq j} \text{Tr}(W_i^T \Sigma_{ij} W_j)$$ Multi-set CCA extends standard CCA to maximize pairwise correlations among \(m\) sets.
Generalized Procrustes $$\min_{Q_i} \sum_{i=1}^m \| X_i Q_i - M \|_F^2$$ Finds optimal orthogonal transformations to align multiple spaces to a central mean \(M\).
Joint PCA (jPCA) $$Z = [X_1, X_2, \dots, X_m] W$$ Computes a shared low-rank subspace across concatenated features.
Shared Autoencoder $$\min_{E_i, D} \sum_{i} \| X_i - D(E_i(X_i)) \|^2$$ Learns non-linear mappings into a shared bottleneck capable of reconstructing all modalities.
Optimal Transport $$\min_{\gamma \in \Pi} \int_{\mathcal{X} \times \mathcal{Y}} c(x,y) d\gamma(x,y)$$ Finds the minimum cost plan \(\gamma\) to transport probability mass from one space to another.
